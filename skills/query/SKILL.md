# Query (위키 기반 지식 검색 및 답변)

## Overview
이 스킬은 벡터 DB와 같은 복잡한 인프라 대신, `wiki/` 폴더 내에 마크다운 파일로 정제되어 축적된 진찬언 수석님의 개념 카드 및 소스 자료를 추적하여 사용자의 질문에 정확하고 풍부한 비즈니스/학습 맥락의 답변을 제공합니다.

## Dependencies
없음

## Quick Start
수석님이 `/query [질문 내용]` 또는 위키 관련 질문을 던졌을 때 작동을 시작합니다.

## Workflow

### 1. 색인 최우선 탐색 (Index Scan)
- 사용자의 질문 키워드가 입력되면, 가장 먼저 `wiki/index.md` 파일을 읽어 관련이 있는 개념(`[[Concept_...]]`) 및 소스(`[[Source_...]]`) 페이지 링크가 존재하는지 확인합니다.

### 2. 관련 위키 페이지 분석 및 링크 추적
- `index.md`에서 매칭되거나 질문 맥락상 깊이 연관된 `wiki/` 내 마크다운 문서를 읽어 정보를 추출합니다.
- 만약 참조한 문서 내에 다른 위키링크(예: `[[Concept_LLM_Wiki]]`)가 걸려 있다면, 해당 문서도 함께 추적하여 맥락의 공백을 메웁니다.
- 필요할 경우, `wiki/` 내에서 Ripgrep(grep_search)을 사용하여 특정 키워드가 본문에 포함된 문서들을 신속하게 필터링합니다.

### 3. 출처 표기 기반 답변 구성
- 위키 문서의 내용을 종합하여 수석님의 비즈니스/기술적 맥락에 맞는 고품질의 전문가 톤 답변을 작성합니다.
- **출처 링크 의무화:** 답변 중간 또는 하단에 반드시 정보의 근거가 된 위키 문서들을 위키링크 형식(`[[문서명]]` 또는 마크다운 파일 링크)으로 정확히 표기하여 수석님이 옵시디언 내에서 타고 들어갈 수 있게 합니다.

### 4. 마지막 보루 검색 (raw/sources 조회)
- 질문한 내용이 정제된 `wiki/` 내에 존재하지 않는 경우, 1차적으로 위키에 내용이 없음을 안내합니다.
- 이후 마지막 수단으로서 불변 원본 저장소인 `sources/` 폴더 하위 문서들까지 전체 검색(grep_search)하여 관련된 원본 조각이 있는지 탐색하고 보충해 줍니다.

## Common Mistakes
- **위키 문서 건너뛰기:** `index.md`나 `wiki/` 내 개념 페이지 조회를 건너뛰고 곧바로 AI의 일반 학습 지식(Hallucination)만으로 답하는 것을 금지합니다. 모든 답변은 반드시 수석님의 볼트 내 지식을 우선시해야 합니다.
- **링크 누락:** 답변의 근거가 된 실제 위키 파일 링크를 누락하면 안 됩니다.
