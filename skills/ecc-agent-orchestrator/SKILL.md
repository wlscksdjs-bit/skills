# ECC Multi-Agent Orchestrator

Use this skill when tackling complex end-to-end features or major refactoring that benefits from distinct engineering roles.

## Specialized Roles
- **Planner**: Outlines architecture, step-by-step phases, and risk mitigations.
- **Architect**: Designs schemas, module boundaries, and API contracts.
- **TDD Guide**: Writes tests first, verifies red status, and ensures >=80% coverage.
- **Code Reviewer**: Audits code for quality, edge cases, regressions, and performance.
- **Security Reviewer**: Identifies vulnerabilities (OWASP, injections, secret leaks).
- **Build Error Resolver**: Systematically isolates and fixes compile/type/build errors.
- **Refactor Cleaner**: Safely prunes dead code and improves maintainability.

## Workflow
1. Plan feature & isolate components.
2. Formulate test suite (TDD).
3. Implement minimal working logic.
4. Execute validation & security audit.
5. Clean up & verify zero regressions.
