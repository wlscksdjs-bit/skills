# Ingest (지식 수집 및 위키 인제스트)

## Overview
이 스킬은 `sources/` 폴더 내에 수석님이 새로 스크랩하거나 추가한 원본 파일을 감지하여 읽고, 핵심 요약 및 엔티티를 정제한 뒤 사용자(수석님)와의 3가지 인터뷰 질문 대화를 통해 최종적으로 `wiki/` 지식 저장소에 연동하는 워크플로우를 자동화합니다.

## Dependencies
없음

## Quick Start
수석님이 "방금 저장한 글 인제스트해줘" 또는 `/ingest`라고 요청하면 작동을 시작합니다.

## Workflow

### 1. 신규 소스 감지 및 본문 분석
- `sources/` 하위 디렉토리(`insights/`, `academic/`, `meetings/`, `business/`)에서 최근에 생성되거나 변경된 마크다운(*.md) 파일을 탐색합니다. (README.md, AGENTS.md 및 시스템 파일 제외)
- 해당 원본 파일을 읽고 내용을 분석합니다. (주의: `sources/` 내의 원본 파일은 불변이며 절대 수정하지 않습니다.)

### 2. 소스 1차 요약 생성
- 수집한 파일의 본문을 분석하여 다음 3가지 항목을 먼저 정제해 사용자에게 보여줍니다.
  - **핵심 주장 (Key Claims)**
  - **언급된 엔티티 (사람, 도구, 조직)**
  - **다루는 개념 (Concepts)**

### 3. 사용자 목적성 인터뷰 (인터랙션)
- 분석 결과와 함께 사용자에게 아래 3가지 인터뷰 질문을 명확하게 건넵니다.
  1. "이 글을 왜 캡처했어?"
  2. "지금 하고 있는 일과 어떻게 연결돼?"
  3. "이걸로 뭘 해보고 싶어?"
- 사용자의 답변을 기다립니다.

### 4. 위키(wiki/) 지식 연동 및 색인/로그 업데이트
- 사용자의 답변이 입력되면 아래 4가지 작업을 순차적으로 실행합니다.
  - **소스 요약 파일 생성:** `wiki/Source_<적절한이름>.md` 파일을 생성합니다. 상단에 YAML Frontmatter를 규격에 맞춰 작성하고, 인터뷰 답변(수집 목적, 업무 연결성, 실행 계획)과 소스 1차 요약을 기록합니다.
  - **개념/엔티티 파일 생성/업데이트:** 소스에서 도출된 핵심 개념이나 엔티티가 기존 `wiki/`에 존재하는지 확인하고, 해당 문서를 업데이트하거나 새 개념 문서(`wiki/Concept_<개념명>.md`)를 생성하여 양방향 링크(`[[WikiLink]]`)를 연결합니다.
  - **색인(index.md) 동기화:** 신규 생성된 위키 페이지들을 `wiki/index.md`에 한 줄 설명(120자 이내)과 함께 추가합니다.
  - **로그(log.md) 기록:** 이번 인제스트 오퍼레이션 내역(CREATE, UPDATE)을 타임라인 순으로 `wiki/log.md`에 추가합니다.

## Common Mistakes
- **소스 원본 수정 금지:** `sources/` 안의 파일 내용을 수정하거나 변경 로그에 기록되지 않은 다른 조작을 가하면 안 됩니다.
- **단선 인덱스 미준수:** `index.md`에 여러 줄의 요약을 적지 않도록 한 줄(120자) 제약을 반드시 준수해야 합니다.
