# ECC Harness Audit

Use this skill to inspect and diagnose agent performance, token efficiency, and project readiness.

## Checkpoints
1. **Rule Compliance**: Are project rules and coding standards defined and up to date?
2. **Context Window**: Are tools and MCP servers kept within reasonable limits (< 80 tools)?
3. **Memory & Learnings**: Are key patterns and learnings preserved across sessions?
4. **Test & Verification Loop**: Are automated tests passing cleanly with zero warnings?
